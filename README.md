3D Rotating Cube with Transformations using OpenGL

Project Description

This project demonstrates a 3D rotating cube using OpenGL and C++. The cube rotates continuously along the X, Y and Z axes with different colours on each face.

Features

- 3D cube drawing using OpenGL
- Six different coloured faces
- Continuous rotation on X, Y and Z axes
- 3D transformations
- Perspective projection
- Depth testing for proper 3D view

Technologies Used

- C++
- OpenGL
- FreeGLUT
- Visual Studio Code
- MSYS2

How to Run

Compile the program:

g++ main4.cpp -o cube.exe -lfreeglut -lopengl32 -lglu32

Run the program:

./cube.exe
